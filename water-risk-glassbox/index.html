What this model does, and does not do

The model answers one question for a mine site. What water risk can the tool describe from the data we have today, and what can it not describe? The model gives a tiered read in three panels. Panel A is pressure. It is what the mine takes or adds. Panel B is condition. It is the state of the basin. Panel C is change. It is what changed since operations began. The panels sit side by side. The model never divides one panel into another. It never gives one blended score.

The model does not compute cause. It cannot say that this mine caused this change. It is built not to. Basin data mixes many users and the climate across a sub-basin. In a belt with many smelters, contamination has many possible sources. So the read stops at timing (the first step of the ladder above). It then states what evidence you need to go further. This boundary is the point. It is not a weakness. The December 2025 WALHI case was won the same way. It used independent measurements next to context, not a model attribution number.

The water-stress result (basin status next to mine pressure)

The result starts with one plain level, from Low to Very High. A non-specialist can read it fast. To show why, the tool puts the basin status next to the water that a mine like this uses. The tool shows the two side by side. It never divides one into the other. To divide them would make a "share of basin stress" claim. The method bans this claim, because no method can defend it.

Water stress (basin) is the Aqueduct 4.0 baseline water-stress class for the sub-basin. The tool shows it as a level (Low under 10 percent, Low-Medium 10 to 20, Medium-High 20 to 40, High 40 to 80, Extremely High over 80). It also shows the 2030 and 2050 projections. This is a published, modelled value. The basin can sit near a class edge, or a dry-season flag can be set. In both cases the level shows that caveat. It does not hide it.

A mine like this would draw is the Panel A pressure. It is the water that a mine of this process type uses. The tool shows it as a measured, permitted, or estimated figure, by tier. It sits next to the basin, so you can see the pressure. The tool never combines it with the basin.

The tool defers the water-quality hazard for now. The chemical watchlist for the process type is still in the full technical read.

How sure are we? (the label on every value)

Every number the tool shows carries a plain label for how sure we are of it, from most sure to least sure: Measured, then From a permit, then Modelled, then Our estimate, then No data. The label is honest about where the value came from. It is separate from which panel the value sits in.

How far can it go on "did the mine cause this?"

Any statement about change sits on a four-step ladder. Each step needs stronger evidence than the last. This tool only ever uses step 1 (timing). The higher steps are shown so you can see the honest boundary, and what it would take to go further.

The rules

The model is 69 rules in eight groups, plus eight forward-looking rules for the Aqueduct 5.0 layer. Every rule cites a source section or a named strawman parameter. Rules run in order: classify, then demand, then condition, then watchlist, then the gap line. Tier, ladder, and banned-construction rules govern every output.

The Aqueduct 5.0 layer

Forward-looking and hypothetical

Aqueduct 5.0 is not released. In this tool it is a demo device. It shows how the same rules get sharper when finer water data arrives. No rule changes. Only the inputs get better. The seasonal screen changes from "not assessed" to a real dry-season class. A published error band replaces the judgment buffer. The demand-vintage flag clears where the basin model includes the local industry. The groundwater "no data" cells get a class.

Here is the honest point. Panel A barely moves. A basin dataset does not know how much water a mine takes. The license request and the ground sample stay the main gaps. The gap line gets shorter. But it never goes away.

How to use this

A water-risk model you can see inside

This tool shows how we screen the water risk of a mine site. It uses the data that is available today. It is a screening model. It is not a verdict. It never says that one mine caused a change.

  1. 1Choose a site. Select one of the three example mines. Or edit any input to build your own. Then press Analyze.
  2. 2Watch it decide. The decision flow shows the path that the model takes. It moves branch by branch. It shows why the model makes each choice.
  3. 3Read the result. You get a plain water-stress level, from Low to High. The basin status appears next to the water that a mine like this uses. The result also shows the one gap that stays. To see more, open the full technical read.

Tip: turn on the Aqueduct 5.0 control. It shows how the same model gets sharper when the water data improves. To read the full method, open the Methodology and rules tab.
