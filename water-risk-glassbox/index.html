What this model does, and does not do

The model answers one question for a mine site. What water risk can the tool describe from the data we have today, and what can it not describe? The model gives a tiered read in three panels. Panel A is pressure. It is what the mine takes or adds. Panel B is condition. It is the state of the basin. Panel C is change. It is what changed since operations began. The panels sit side by side. The model never divides one panel into another. It never gives one blended score.

The model does not compute cause. It cannot say that this mine caused this change. It is built not to. Basin data mixes many users and the climate across a sub-basin. In a belt with many smelters, contamination has many possible sources. So the read stops at timing (the first step of the ladder above). It then states what evidence you need to go further. This boundary is the point. It is not a weakness. The December 2025 WALHI case was won the same way. It used independent measurements next to context, not a model attribution number.

The water-stress result (basin status next to mine pressure)

The result starts with one plain level, from Low to Very High. A non-specialist can read it fast. To show why, the tool puts the basin status next to the water that a mine like this uses. The tool shows the two side by side. It never divides one into the other. To divide them would make a "share of basin stress" claim. The method bans this claim, because no method can defend it.

Water stress (basin) is the Aqueduct 4.0 baseline water-stress class for the sub-basin. The tool shows it as a level (Low under 10 percent, Low-Medium 10 to 20, Medium-High 20 to 40, High 40 to 80, Extremely High over 80). It also shows the 2030 and 2050 projections. This is a published, modelled value. The basin can sit near a class edge, or a dry-season flag can be set. In both cases the level shows that caveat. It does not hide it.

A mine like this would draw is the Panel A pressure. It is the water that a mine of this process type uses. The tool shows it as a measured, permitted, or estimated figure, by tier. It sits next to the basin, so you can see the pressure. The tool never combines it with the basin.

The tool defers the water-quality hazard for now. The chemical watchlist for the process type is still in the full technical read.

How sure are we? (the label on every value)

Every number the tool shows carries a plain label for how sure we are of it, from most sure to least sure: Measured, then From a permit, then Modelled, then Our estimate, then No data. The label is honest about where the value came from. It is separate from which panel the value sits in.

How far can it go on "did the mine cause this?"

Any statement about change sits on a four-step ladder. Each step needs stronger evidence than the last. This tool only ever uses step 1 (timing). The higher steps are shown so you can see the honest boundary, and what it would take to go further.

The rules

The model is 69 rules in eight groups, plus eight forward-looking rules for the Aqueduct 5.0 layer. Every rule cites a source section or a named strawman parameter. Rules run in order: classify, then demand, then condition, then watchlist, then the gap line. Tier, ladder, and banned-construction rules govern every output.

When data is missing or unknown

This is the part leadership asks about most. What does the tool do when you cannot give it a piece of information? The rule is the same every time. When an input is not known, the tool lowers its confidence and shows that clearly. It never invents a value to fill the gap.

Production capacity unknown
You can mark capacity as "unknown". Without a yearly capacity, the tool cannot turn a per-tonne water rate into a total volume. So it shows only the per-tonne intensity range, marks the water-use figure as "No data", and asks for the capacity. It does not guess a volume.
Process route unknown
The process route sets the water use per tonne, and the candidate routes for the same ore can differ too much to average. For nickel laterite, the HPAL and RKEF routes differ in total water footprint by about 17 times, which is far past the tool's limit for a single range. The tool refuses one merged number and shows an "if HPAL / if RKEF" fork, so the reader sees both cases.
No metered figure and no permit figure
The tool cannot state a measured or a permitted water withdrawal. If the process route and the capacity are known, it drops to a calculated estimate shown as a range. If not, it reports "No data" and routes the case to disclosure.
No site measurement for contaminants
The tool still shows which contaminants to watch for, based on the ore and the process. Where there is no site sample, it marks those rows "process chemistry, not site-measured". An empty watchlist is a data gap, not an all-clear.
Basin data (water stress, riverine flood risk, groundwater trend)
The tool always reads these values from Aqueduct 4.0 for the site location, so you do not enter them and they are never "user-missing". Groundwater trend data is thin in Aqueduct for many basins. Where Aqueduct reports no significant trend, or has no coverage, the tool shows that plainly and does not fill the gap.

The tool is a screening aid. It shows a data gap as a gap, not as safety.

Forward-looking and hypothetical

In this tool, Aqueduct 5.0 means one thing. It is the same Aqueduct data shown at about 10 times finer resolution (downscaled). It is not a claim about the other parts of a future Aqueduct 5.0 release. Aqueduct 5.0 is not released. Here it is a demo device. It shows how the same rules get sharper when finer water data arrives. No rule changes. Only the inputs get better. The seasonal screen changes from "not assessed" to a real dry-season class. A published error band replaces the judgment buffer. The demand-vintage flag clears where the basin model includes the local industry. The groundwater "no data" cells get a class.

Here is the honest point. Panel A barely moves. A basin dataset does not know how much water a mine takes. The license request and the ground sample stay the main gaps. The gap line gets shorter. But it never goes away.

How this model works

A water-risk model you can see inside

This tool screens the water risk of a mine site from the data available today. Here is the whole model in three parts. It is a screening model, not a verdict. It never says that one mine caused a change.

  1. INWhat goes in. You describe the mine: its commodity, its process route, and its size. The basin data comes in on its own. The tool reads water stress, flood risk, groundwater trend, and seasonal variability from Aqueduct 4.0 for the location. You do not type those.
  2. RUNHow it decides. Plain rules run in three branches. First, what kind of water risk the basin has, too little water, too much at times, or mixed. Second, how trustworthy the water-use figure is, from measured down to unknown. Third, which contaminants to watch, from the ore and process. You watch each step and see why.
  3. OUTWhat comes out. A plain water-stress level, from Low to High, with an uncertainty band when the data is thin. The tool shows the water a mine like this uses next to the basin state. It never divides one into the other. It ends with the one data gap that remains.

Tip: pick an example site or any location, press Analyze, then turn on Aqueduct 5.0 to see the read get sharper. For the full method, open the Methodology and rules tab.
